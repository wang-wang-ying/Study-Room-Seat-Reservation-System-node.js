# Study-Room-Seat-Reservation-System-node.js
# 校园自习室座位预约系统

### 1、系统功能
高校自习室场景的预约管理平台，采用前后端分离架构， 实现自习室管理、座位管理、座位预约、预约管理、学生管理、系统管理等核心业务功能!

· 登录

· 首页（数据统计大盘）

· 自习室管理：自习室列表| 座位管理

· 座位预约：座位预约 | 我的预约（取消预约、签到、签退）

· 预约管理：预约记录

· 学生管理：学生列表 | 分配角色

· 系统管理：账号管理 | 角色管理 | 菜单管理

### 2、使用技术

· 后端：Node.js 20 + Express

· 前端：Vue 3 + Element Plus

· 数据库：MySQL 8.0

· 状态管理：Pinia

· 构建工具：Vite

· 数据可视化：ECharts

· 开发工具：VSCode / WebStorm
